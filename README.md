# DesignsCtrl LLMs.txt Generator

A complete Next.js 14 web app for generating AI-friendly `llms.txt` files.

## Run locally

```bash
npm install
npm run dev
```

Open:

```bash
http://localhost:3000
```

## Features

- Website URL mode
- Sitemap URL mode
- Paste multiple URLs mode
- Auto sitemap detection
- Extracts title and meta description
- Preview generated content
- Copy button
- Download `llms.txt`
- Premium responsive SaaS UI
